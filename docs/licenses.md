# 依存 OSS・データのライセンス一覧

依存関係の追加・変更時はこの表を更新すること。本リポジトリの**コード**ライセンスは未決、**配布データ (地域パッケージ)** は ODbL 1.0 で確定 ([ADR-0002](adr/0002-oss-licensing.md))。

## 配布する地域パッケージのライセンス (ADR-0002 決定)

アプリに配信する `region-<mesh>.sqlite` / `tiles-<mesh>.mbtiles` は OSM 由来の派生データベースを含むため、**ODbL 1.0 で配布**し、以下を順守する。

- **帰属表示**: 地図 UI に「© OpenStreetMap contributors」を常時表示 (避難場所は「© 国土地理院」、DEM は「© 国土地理院」も併記)
- **share-alike / 無償入手**: パッケージは公開バケットから無償で入手可能にする (ODbL の履行そのもの)。認証・署名 URL でのアクセス制限は anti-TPM 条項と衝突するため採らない
- **A40 の条件付き県は公開パッケージから除外**: 浸水フラグに使う A40 が条件付き公開の都道府県は、公開配布物からその由来フラグを外す (正規化段階で対象県を絞る)。**県別の利用条件精査は公開ローンチ前の残課題**

## データソース

| データ | ライセンス | 義務・注意点 |
|---|---|---|
| OpenStreetMap | ODbL 1.0 | 帰属表示必須。抽出・加工した道路グラフは「派生データベース」に当たり、配布は ODbL share-alike の対象。**方針決定済み**: 配布パッケージを ODbL 1.0 + OSM 帰属で公開配信する (上記「配布する地域パッケージのライセンス」/ ADR-0002) |
| 国土数値情報 津波浸水想定データ (A40) | 公共データ利用規約 (PDL1.0) + 県別条件 | 出典明示 + 加工した旨の表示。**大多数の県は商用・再配信可だが、京都(26)・愛媛(38)・長崎(42)・宮崎(45) は条件付き** (要連絡/非商用のみ)。これらは `scripts/a40-redistribution-denylist.txt` で公開配布パッケージから除外する (ADR-0002 追記)。**ローンチ前に県別条件の最終確認が必要** |

| 指定緊急避難場所データ (国土地理院 → G空間情報センター配信) | CC BY 4.0 | 帰属表示必須 (国土地理院)。商用利用・再配布可 |
| 地理院 DEM / 地理院タイル | 測量法 + 政府標準利用規約 (CC BY 4.0 互換) | 出典明示。測量成果の複製・使用申請が必要になる利用形態に注意 |
| DMDATA.jp 電文 | 利用規約 (有償契約) | OSS ではない。再配布条件を契約で確認すること |

|---|---|---|---|
| MapLibre Native | BSD-2-Clause | ✅ アプリに同梱 | 帰属表示のみ。コピーレフトなし |
| Go 標準ライブラリ | BSD-3-Clause | ✅ バイナリに静的リンク | 帰属表示のみ |

| tilemaker | FTWPL | ❌ ビルドツールのみ | 義務なし |
| OpenTofu | MPL-2.0 | ❌ インフラツールのみ | 義務なし |
| Nix / nixpkgs | LGPL-2.1 / MIT | ❌ 開発環境のみ | 義務なし |

## 互換性の要点

- アプリ配布物に入るのは MapLibre (BSD) と Go ランタイム (BSD) のみで、コピーレフトの伝播はない。App Store 配布と競合するライセンスは現時点でなし
- **OSM/ODbL の派生データベース問題は方針決定済み** (ADR-0002): 配布パッケージを ODbL 1.0 + 帰属表示で公開配信する。残るブロッカーは A40 条件付き県の除外精査
