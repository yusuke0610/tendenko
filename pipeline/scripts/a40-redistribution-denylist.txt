# A40 (国土数値情報 津波浸水想定) の再配布制限がある都道府県コード。
# 公開配布パッケージ (ODbL/公開 GCS で世界に無償配信、ADR-0002) から除外する県。
#
# 根拠: 国土数値情報 A40 は県別に利用条件が異なり、大多数は出典明示で商用・再配信可
# (政府標準利用規約/PDL1.0 準拠) だが、一部県は原典 (都道府県) が独自条件を課している
# (KsjTmplt-A40 の県別「制約条件」欄)。公開配布は商用利用を含みうる無償公開のため、
# 「要事前連絡」「非商用のみ再配信」の県は保守的に除外する。
#
# 重要: 下記は 2026-07-28 時点の調査に基づく暫定リストであり、法的な最終判断ではない。
# **公開ローンチ前に各県の最新の利用条件を国土数値情報の県別ページで再確認すること**
# (ADR-0002 のブロッカー)。開発・ローカル検証で全県を含めたい場合は
# A40_INCLUDE_RESTRICTED=1 を付けて normalize-a40.sh を実行する。
#
# 形式: 行頭の都道府県コード (JIS X 0401) を読む。# 以降はコメント。
#
26  # 京都府: 商用利用は京都府 (災害対策課) への事前連絡が必要
38  # 愛媛県: 再配信は防災・減災目的の非商用に限る
42  # 長崎県: 商用利用・再配信は事前連絡が必要
45  # 宮崎県: 商用利用・再配信は事前連絡が必要
#
# 参考: 香川県 (37) は A40 として提供されていない (ダウンロード不可) ため、そもそも
# 手元データに無く除外する必要がない (ADR-0003 の欠落 3 県の 1 つ)。
