# 依存 OSS・データのライセンス一覧

依存関係の追加・変更時はこの表を更新すること。本リポジトリ自体のライセンスは未決 ([ADR-0002](adr/0002-oss-licensing.md))。

## データソース

| データ | ライセンス | 義務・注意点 |
|---|---|---|
| OpenStreetMap | ODbL 1.0 | 帰属表示必須。抽出・加工した道路グラフは「派生データベース」となり、公開配布する場合は ODbL での share-alike 義務が生じる可能性が高い。**地域パッケージの配布形態が決まる ADR-0003 時に法的整理が必要** |
| 国土数値情報 津波浸水想定データ (A40) | 国土数値情報利用約款 (政府標準利用規約準拠) | 出典明示。**大多数の都道府県はオープンデータ (商用利用可・再配信可) だが、一部県は条件付き公開**。全国パッケージを公開配布する前に都道府県別の利用条件を再確認すること (ADR-0003 の実データ取得元追記を参照) |
| 指定緊急避難場所データ (国土地理院 → G空間情報センター配信) | CC BY 4.0 | 帰属表示必須 (国土地理院)。商用利用・再配布可 |
| 地理院 DEM / 地理院タイル | 測量法 + 政府標準利用規約 (CC BY 4.0 互換) | 出典明示。測量成果の複製・使用申請が必要になる利用形態に注意 |
| DMDATA.jp 電文 | 利用規約 (有償契約) | OSS ではない。再配布条件を契約で確認すること |

## ライブラリ・ツール

| 依存 | ライセンス | 配布物に含まれるか | 注意点 |
|---|---|---|---|
| MapLibre Native | BSD-2-Clause | ✅ アプリに同梱 | 帰属表示のみ。コピーレフトなし |
| Go 標準ライブラリ | BSD-3-Clause | ✅ バイナリに静的リンク | 帰属表示のみ |
| GDAL | MIT | ❌ ビルドツールのみ | 義務なし |
| osmium-tool | GPL-3.0 | ❌ ビルドツールのみ | パイプラインで実行するだけで、成果物にコードは含まれない → GPL 伝播なし |
| tilemaker | FTWPL | ❌ ビルドツールのみ | 義務なし |
| OpenTofu | MPL-2.0 | ❌ インフラツールのみ | 義務なし |
| Nix / nixpkgs | LGPL-2.1 / MIT | ❌ 開発環境のみ | 義務なし |

## 互換性の要点

- アプリ配布物に入るのは MapLibre (BSD) と Go ランタイム (BSD) のみで、コピーレフトの伝播はない。App Store 配布と競合するライセンスは現時点でなし
- 最大の未整理点は **OSM/ODbL の派生データベース問題** (地域パッケージを公開 CDN で配る場合)。ADR-0003 とあわせて結論を出す
