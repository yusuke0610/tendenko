# ADR-0002: 本リポジトリのライセンス選定

- ステータス: Partially Accepted — **配布データ (地域パッケージ) 側は決定 (2026-07-25)。コード側は未決**
- 日付: 2026-07-18 (データ側の決定を 2026-07-25 に追記)
- プロジェクト: tendenko

> 注記: 本 ADR はライセンス順守のための**エンジニアリング上の設計判断**を記録するもので、法的助言ではない。公開配布の前に、特に A40 の都道府県別利用条件 (下記) については最終的な確認が必要。

## コンテキスト

tendenko を OSS として公開するか、公開する場合どの範囲 (app / server / pipeline / docs) をどのライセンスで公開するかは**まだ決めていない**。決定まで LICENSE ファイルは意図的に置かない — ライセンス表記のないリポジトリは法的にはデフォルトで all rights reserved であり、「未決のまま曖昧に OSS 扱いされる」ことを防ぐ。

## 決定に影響する論点

- **OSM/ODbL の派生データベース問題**: 地域パッケージを公開配布する場合、パッケージ自体に ODbL の share-alike が及ぶ可能性が高い ([docs/licenses.md](../licenses.md) 参照)。コードのライセンスとデータのライセンスは分けて整理する必要がある
- **防災アプリとしての公益性**: アルゴリズム (浸水リスク考慮の経路探索) の検証可能性・第三者監査の観点では公開に利がある
- **範囲の分割**: app のドメイン層のみ公開、server/infra は非公開、といった部分公開も選択肢
- 公開する場合の候補: Apache-2.0 / MIT (コード)、パッケージデータは ODbL 継承

## 決定

### データ側 (配布する地域パッケージ) — Accepted (2026-07-25)

**配布する地域パッケージ (region.sqlite / tiles.mbtiles) は ODbL 1.0 で配信し、OSM の帰属表示を行う。バケットは公開 (public) にする。**

根拠 (一次情報で確認):

- region.sqlite の道路グラフは OSM の構造化データを抽出・加工したものであり、ODbL の **Derivative Database (派生データベース)** に当たる (データ抽出目的であり Produced Work ではない)。tiles.mbtiles は地図描画用の Produced Work だが、いずれも OSM に由来する
- 派生データベースを第三者 (アプリ利用者) に conveyance する以上、ODbL の **share-alike が発火**する。義務は (1) 派生 DB を ODbL 1.0 で提供、(2) 帰属表示「© OpenStreetMap contributors」を利用者に提示、(3) インターネット配布は無償で入手可能にする
- ODbL の **anti-TPM (技術的制限) 条項**により、認証・署名 URL 等でアクセスを制限しても、OSM 由来部分については制限のない無償入手版を別途提供する義務が残る。**したがって OSM 由来データについては「公開配布」がむしろ share-alike の履行そのもの**であり、アクセスを絞る設計 (署名 URL 等) は法的にちぐはぐになる。→ 公開バケットで配信する

**残る条件 (公開再生成の前提)**:

- **A40 (津波浸水想定) の都道府県別利用条件**。region.sqlite のエッジには A40 由来の浸水フラグが焼き込まれており、A40 が**条件付き公開の都道府県**については、その派生 DB を公開配布すると条件付きデータを再配布することになる。公開再生成の前に、条件付き県を特定し、**公開パッケージからはその県の A40 由来フラグを除外**する (= 標高ベース経路のみの縮退。東京都・福井県・香川県が既に A40 欠落で同状態、ADR-0003)。除外は正規化段階 (`pipeline/scripts/normalize-a40.sh` に含める都道府県) で行う。避難場所 (CC BY 4.0) と DEM (政府標準利用規約) は帰属表示で足りる
- **帰属表示のアプリ実装**。地図 UI に「© OpenStreetMap contributors」を常時表示する (FR-02 の app 配線に含める)

### コード側 (app / server / pipeline / infra) — 未決

コードのライセンス (Apache-2.0 / MIT 等) と公開範囲は**引き続き未決**。データ側と独立に決められるため、別途決定する。それまで LICENSE ファイルは置かない (デフォルト all rights reserved のまま)。

## 帰結

- **配布パッケージには OSM 帰属 + ODbL 1.0 を明示**する ([docs/licenses.md](../licenses.md) にデータ配布ライセンスを追記済み)。配信バケットは public にする ([ADR-0004](0004-region-package-delivery.md))
- **公開再生成の前に A40 条件付き県の除外が必須**。除外機構は実装済み (下記追記)。ただし denylist の正確性は暫定であり、**公開ローンチ前の各県利用条件の最終確認はブロッカーとして残る** (法的最終判断はプロジェクト側)
- コードのライセンス未決のうちは外部コントリビューションを受け付けられない

## 追記 (2026-07-28): A40 県別利用条件の精査と除外機構の実装

A40 の利用条件を一次情報 ([国土数値情報 A40](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A40-v2_1.html) / [利用約款](https://nlftp.mlit.go.jp/ksj/other/agreement.html)) で確認した。

- **全体**: 公共データ利用規約 (PDL1.0) 準拠。大多数の県は出典明示で商用・再配信可。加工データの配布可 (出典 + 加工した旨の表示が必要)
- **県別の差異**: 原典が都道府県のため、一部県は独自条件を課している (KsjTmplt-A40 の県別「制約条件」欄)。手元の 44 県のうち条件付きと判明したもの: **京都府 (26, 商用は要連絡)・愛媛県 (38, 非商用のみ再配信)・長崎県 (42, 要連絡)・宮崎県 (45, 要連絡)**。香川県 (37) は A40 として提供不可 (ADR-0003 の欠落 3 県)
- **実装**: `pipeline/scripts/a40-redistribution-denylist.txt` に再配布制限県のコードを列挙し、`normalize-a40.sh` がデフォルトでその県を公開配布パッケージから除外する (該当県の沿岸メッシュは浸水フラグ無しの縮退動作。標高ベース経路は機能する)。開発・ローカル検証で全県を含めたいときは `A40_INCLUDE_RESTRICTED=1`
- **正直な限界**: 上記の県別条件は 2026-07-28 時点の Web 情報に基づく暫定であり、法的な最終判断ではない。**公開ローンチ前に各県の最新の利用条件を国土数値情報の県別ページで再確認する**こと (このセッションでは実際の全国再生成・公開配信は行っていない = ローンチ未実施)
