# ADR-0002: 本リポジトリのライセンス選定 (未決)

- ステータス: Proposed (未決)
- 日付: 2026-07-18
- プロジェクト: tendenko

## コンテキスト

tendenko を OSS として公開するか、公開する場合どの範囲 (app / server / pipeline / docs) をどのライセンスで公開するかは**まだ決めていない**。決定まで LICENSE ファイルは意図的に置かない — ライセンス表記のないリポジトリは法的にはデフォルトで all rights reserved であり、「未決のまま曖昧に OSS 扱いされる」ことを防ぐ。

## 決定に影響する論点

- **OSM/ODbL の派生データベース問題**: 地域パッケージを公開配布する場合、パッケージ自体に ODbL の share-alike が及ぶ可能性が高い ([docs/licenses.md](../licenses.md) 参照)。コードのライセンスとデータのライセンスは分けて整理する必要がある
- **防災アプリとしての公益性**: アルゴリズム (浸水リスク考慮の経路探索) の検証可能性・第三者監査の観点では公開に利がある
- **範囲の分割**: app のドメイン層のみ公開、server/infra は非公開、といった部分公開も選択肢
- 公開する場合の候補: Apache-2.0 / MIT (コード)、パッケージデータは ODbL 継承

## 決定

**未決。** LICENSE ファイルは置かない。決定時に本 ADR を更新し、ステータスを Accepted に変更する。

## 帰結

- 決定までは外部コントリビューションを受け付けられない (ライセンス不明のため)
- ADR-0003 (データパイプライン設計) で配布形態が決まった後に、データ側のライセンス整理とあわせて結論を出すのが自然な順序
